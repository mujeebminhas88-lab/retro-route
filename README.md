# retro-route
Retro Route 3D isometric game

Ride. Deliver. Relive.
Retro Route is a nostalgic 3D arcade delivery game inspired by the freedom of growing up in the 90s and early 2000s. Built with Godot 4, the game combines modern gameplay with retro aesthetics, placing players in vibrant suburban neighborhoods where they deliver newspapers, parcels, pizzas, and special event items while navigating traffic, obstacles, and busy streets.
Players choose between two teenage characters, hop on a BMX, and complete delivery routes across handcrafted neighborhoods designed to evoke childhood memories. Rather than focusing on hyper-realistic simulation, Retro Route aims to capture the feeling of riding through the neighborhood after school—exploring, discovering shortcuts, and enjoying simple arcade-style fun with satisfying bike physics and rewarding progression.
The project is being developed with a mobile-first approach for Android, emphasizing smooth performance, accessible controls, and a polished user experience. Planned features include multiple neighborhoods, unlockable bikes and cosmetics, seasonal events, achievements, and replayable route-based gameplay designed for short, engaging play sessions.
Retro Route is an original indie project focused on delivering a modern take on a classic arcade experience while celebrating the nostalgia of a generation that grew up outdoors.
