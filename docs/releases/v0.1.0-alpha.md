# Retro Route 3D — v0.1.0-alpha

**Released:** 2026-07-27
**Live URL:** https://mujeebminhas88-lab.github.io/retro-route/
**Commit:** `6731644` (tag `v0.1.0-alpha` created locally on this commit; see note at the bottom)

First production release. Promotes the approved work from Milestones 1-5 to `main` and to the public Web deployment.

## What's in this release

**Project Foundation**
- Real Godot 4.3 project (previously the repo held only placeholder files): proper `project.godot`, `res://` folder structure, `.gitignore`, Android export preset, minimal boot-verification scene.

**Continuous Deployment**
- GitHub Actions pipeline: every push to `main` builds the Godot Web export, verifies the output, and deploys to GitHub Pages automatically. Godot editor/templates are downloaded with pinned SHA-512 checksums and cached between runs.

**First Playable Prototype (Locomotion)**
- Third-person arcade locomotion: walk/run, acceleration/deceleration/momentum, air control, an arcade jump with variable height and landing detection.
- Smooth SpringArm3D chase camera that auto-orients behind the player's facing direction, with built-in collision avoidance.
- Mobile touch controls built from scratch (virtual joystick + jump button), unified with keyboard input behind one `PlayerInput` contract.
- Visual polish: placeholder character, ground shadow, movement dust particles, squash/stretch landing feedback.

**First Complete Gameplay Loop (Deliveries)**
- Throw newspapers at an auto-targeted mailbox with a dedicated button; deterministic kinematic arc flight; hit/miss decided by throw-time distance to target.
- `DeliveryManager` centralizes scoring and active-mailbox rotation; a new mailbox activates automatically after each delivery.
- Minimal HUD (score + "Delivery Complete!" flash), floating "+10" popup, particle burst, procedurally-generated success chime.
- Verified end-to-end in the real Web build: a keyboard session reached Score: 10, a touch session reached Score: 30, both with zero console/page errors.

## Known limitations

- Android export preset is configured but untested end-to-end (no Android SDK/export templates in the CI pipeline yet).
- No off-screen indicator toward the active mailbox when it's out of view.
- Placeholder single-tone audio; no music.
- Game Bible / art direction not yet written up.
